
# GRZ Secondary School Management System

An Offline School Management System with Health Room Module designed for Zambian Government (GRZ) Secondary Schools.

## 👨‍🎓 Developed By
James M Chibo - Final Year Project - 2026

## ✨ Features
- Student Registration & Management
- Staff & Teacher Management  
- Class & Subject Management
- Examination & Results Processing
- Fees & Finance Management
- **Health Room / Sick Bay Module** (Main Focus)
- Attendance Tracking
- Offline First - Works without internet
- Report Generation

## 💻 Tech Stack
- PHP
- MySQL
- HTML, CSS, JavaScript
- Bootstrap
- XAMPP Server

## 📥 How to Install
1. Download or clone this repository
2. Copy folder to htdocs in XAMPP
3. Import database.sql file in phpMyAdmin
4. Start Apache and MySQL
5. Run http://localhost/GRZ-Secondary-School-Management-System

## 🎯 Project Objective
To digitize school records and improve healthcare tracking for learners in GRZ Secondary Schools in Zambia, reducing paperwork and improving data access.
